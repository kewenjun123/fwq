# 识字小站 · 常用汉字跟读

一个纯静态的中文识字网站：点一点汉字，就能听到它怎么读。收录 **355 个日常高频汉字**，按 11 个主题分类，支持语音播报、拼音搜索、连续朗读和「听音选字」练习。

## 怎么打开

**最简单：** 双击 `index.html`，用 Chrome 或 Edge 打开即可（纯静态，无需安装任何东西、不需要联网）。

**或者在目录里起一个本地服务：**

```powershell
cd "D:\Deepseek harness\hanzi-site"
python -m http.server 8080      # 然后访问 http://localhost:8080
# 或者用 Node：
npx --yes serve -l 8080 .
```

## 功能

| 功能 | 说明 |
| --- | --- |
| 点字听音 | 点任意字卡，立即朗读该字，并弹出详情卡 |
| 字卡详情 | 大字、拼音、释义、例词；例词也能逐个点读；支持「上一个 / 下一个」翻页 |
| 连续朗读 | 点「连续朗读本页」按顺序自动播报「字 + 首个例词」，当前朗读的卡片会高亮，可随时停止 |
| 搜索 | 支持汉字、带声调拼音（`shuǐ`）、无声调拼音（`shui`）、释义和例词 |
| 分类浏览 | 数字与数量、人与家人、身体部位、自然天地、动物世界、颜色、动作、方位与时间、生活与学习、样子与感觉、常用高频字 |
| 音色 / 语速 | 可选择系统里的中文发音人，语速 0.4×–1.4× 可调（默认 0.8×，适合跟读） |
| 听音选字 | 随机报一个字，从 4 个选项里选出来；答错会给出正确答案并朗读，带得分统计 |
| 夜间模式 | 右上角一键切换，配置会记在浏览器本地 |
| 快捷键 | `Esc` 关闭弹层 / 停止朗读，`←` `→` 切换上/下一个字，空格重播当前字 |

## 语音说明（重要）

朗读使用浏览器内置的 **Web Speech API**（`speechSynthesis`），不需要联网、不消耗流量，但用的是**系统里已安装的语音包**：

- 页面顶部的「音色」下拉会自动列出所有可用发音人，中文语音会排在「中文普通话音色」分组里。
- 本机实测可用：**晓晓 Online (Natural)**（Edge 自带，音质最好）。
- 如果提示「没有检测到中文语音包」：Windows 到 *设置 → 时间和语言 → 语言和区域 → 中文(简体) → 语言选项* 里安装「语音包」，或用 Edge 打开。
- 部分浏览器的语音列表是异步加载的，页面会在 1 秒内自动刷新一次下拉；若仍为空，刷新页面即可。
- 多音字（如 长、发、少、只、为）默认读常见音，**以例词中的读音为准**，所以连读时是「字 + 例词」一起播报。

## 文件结构

```
hanzi-site/
├── index.html    页面结构
├── styles.css    样式（含夜间模式与响应式）
├── data.js       汉字数据：[汉字, 拼音, 释义, 例词|例词|例词]
├── app.js        交互逻辑（语音、渲染、搜索、练习）
├── check.js      自检脚本（node check.js）
└── README.md     本文件
```

## 维护与扩展

**加字**：直接编辑 `data.js`，在对应分类的 `chars` 里按 `["字", "pīn", "释义", "例词1|例词2"]` 添加即可，页面无需改动。

**自检**：改完数据后跑一次

```powershell
node check.js
```

它会检查数据字段是否完整、有无重复字、HTML/CSS/JS 之间的 id 与类名引用是否对得上。

## 已知限制

- 释义和例词是面向识字启蒙的简化说法，不是字典级释义。
- 没有笔顺动画（需要额外的笔顺数据）。
- 语音效果取决于系统语音包；「晓晓 Online (Natural)」这类在线自然音色需要联网。
